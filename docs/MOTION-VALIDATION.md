# Покадровое поглаживание Чудика

8 ноября 2026, МСК.

Для каждого из трёх возрастов нарисован прозрачный атлас 4×4 (16 кадров), всего 48 кадров. Отдельный пустой остров остаётся неподвижным; персонаж расположен поверх него. Кадры включают моргание, движение ушек, отклик на прикосновение, наклон головы, довольную улыбку, ласковые движения влево/вправо и подмигивание. Дыхание добавлено небольшим масштабированием только прозрачного слоя персонажа; рамка сцены не меняется.

Новая анимация работает на острове и в карточке Чудика. Ожидание использует цикл моргания. Поглаживание длится шесть секунд, последние 1,2 секунды — спокойная поза. Повторы меняют сторону ласкового движения; каждый третий отклик заканчивается подмигиванием. Остальные питомцы сохраняют ранее реализованные реакции. Еда, игра и сон Чудика также сохраняют прежние рисунки.

Тайминг рассчитывается от прошедшего времени, а не количества callback-вызовов. Скрытая вкладка и выход сцены из viewport останавливают таймер кадров; после возвращения старые кадры не накапливаются. При reduced-motion показывается статичная довольная поза. Сначала загружаются фон и атлас текущего возраста; при неудаче остаются прежний портрет и реакции. Предыдущие изображения не удалялись.

Проверено:
- npm test — 14/14, включая три новых теста тайминга.
- npm run typecheck — успешно.
- npm run build — успешно.
- git diff --check — успешно.
- Все три WebP имеют alpha-канал с прозрачными и непрозрачными пикселями; сетка квадратная 4×4; атласы и фон присутствуют в сборке.
- Исходные изображения просмотрены при генерации. Новый набор WebP суммарно 2 197 566 байт.

Не проверено: визуальное качество компоновки и движения в готовом интерфейсе, реальный Telegram на телефоне. Известный блокер предпросмотра этой среды — `sites-preview` / `listen EPERM 127.0.0.1`; после него не обнаружено подтверждений восстановления инфраструктуры, поэтому обходной сервер не запускался.

Ручная приёмка: дождаться моргания, погладить три раза с интервалом и быстро подряд, сменить возраст/раздел, свернуть и открыть Telegram, включить сокращение движения. Проверить устойчивость острова, отсутствие обрезанных ушей/крыльев и рамок, положение лап, загрузку на медленном соединении. Автоматические тесты тайминга не заменяют эту визуальную проверку.

После подготовки анимации добавлены версии изображений 1×/2×. См. [RETINA-VALIDATION.md](RETINA-VALIDATION.md), включая ограничение детализации при увеличении исходников.
