# Отступы и мобильная вёрстка

16 ноября 2026, МСК. Правки затрагивают только CSS; правила, состояние профилей и графика сохранены.

В боковой колонке острова задан общий интервал 24 px между панелями. Заголовки, пояснения, разделители и кнопки получили отдельные отступы. У эволюции появилась дистанция между условиями и подтверждением, у мини-игры — между полем, подписью и сохранением результата. Уточнены интервалы в карточке питомца и подарках.

До 420 px кнопки заданий располагаются под описанием. В мобильном альбоме история развития представлена строками с иллюстрацией и читаемым текстом вместо трёх тесных колонок. На первом выборе питомца описание до 420 px переносится под сцену. Панели растут по содержимому, высота текстовых блоков не ограничена.

Проверки: `npm test` — 44/44; `npm run typecheck` — успешно; `npm run build` — успешно. Сборка сохраняет 72 прямых 2× ресурса. Эти проверки не доказывают визуальную корректность.

Визуальная проверка браузером не выполнена: `sites-preview start /workspace/integrated` завершился `listen EPERM 127.0.0.1`; статус — остановлен. Ограничение инфраструктуры не обходилось. Реальный Telegram на телефоне этой версией отдельно не проверен.

Для визуальной приёмки: экраны 320/375/390/430 px и планшет/десктоп; остров со всеми панелями; выполненные и незавершённые задания; эволюция и подтверждение; мини-игра до/после раунда; альбом, модальная карточка, подарки, правила и первый выбор нового профиля. Проверить переносы, увеличение текста и отсутствие перекрытия нижней навигацией. Существующий профиль ради первого выбора не сбрасывать.

Следующий функциональный этап остаётся в плане: короткое знакомство после первого выбора и разнообразие ежедневных заданий. В этот выпуск они не входят.
