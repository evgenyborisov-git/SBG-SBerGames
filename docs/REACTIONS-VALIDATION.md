# Реакции всех питомцев

8 ноября 2026, МСК.

Исправлена конкретная причина появления краёв: глобальный `button:active` уменьшал всю кнопку-сцену до 97%. Для `.pet-scene` и `.guardian-touch` теперь явно запрещены transform/animation; визуальные слои имеют запас по 4% с каждой стороны и обрезаются неподвижным viewport. Двигаются только декоративные частицы. Старые CSS-классы reaction-N больше не назначаются сцене.

Нарисованы 12 WebP-атласов размером 1448×1086 (4 столбца × 3 строки), всего 144 позы. Столбцы: удовольствие от ласки, еда, игра, сон. Строки: малыш, подросший, хранитель. Имена файлов совпадают с ID видов в каталоге. Общий размер новых WebP — 4 153 064 байта; загружается атлас показанного питомца, а не весь набор. Исходные игровые и галерейные иллюстрации сохранены.

Остров: касание Чудика и «Тихая минутка» меняют визуальную реакцию; кормление, игра и награда запускают реакцию после успешного ответа игрового API. Все три возраста реагируют. Награда использует счастливую позу с золотыми частицами.

Галерея: для всех 12 видов и трёх возрастов доступны касание и четыре кнопки реакций. Это демонстрация без игровых запросов и расхода ресурсов. Покадровая непрерывная анимация тела не реализована: используются отдельно нарисованные позы, плавное смешивание слоёв и частицы. Поддерживается reduced-motion.

Загрузка атласа кешируется. Таймер реакции запускается после загрузки. Повторное действие отменяет прежний таймер; устаревшие асинхронные результаты отбрасываются. Смена вида/формы и закрытие карточки очищают ожидающие реакции. При ошибке загрузки остаётся исходный портрет и выводится предложение повторить.

Проверки этого изменения:
- npm test: 11/11 существующих тестов игры и HTTP/Telegram API; это не тесты визуальных реакций.
- npm run typecheck: успешно.
- npm run build: успешно.
- git diff --check: успешно.
- Проверены размеры всех 12 атласов, квадратная сетка 4×3 и наличие файлов в dist/client.
- Все новые атласы визуально просмотрены при генерации.

Ограничение: sites-preview снова завершился с `listen EPERM 127.0.0.1`; проверка готового интерфейса и screenshot QA не выполнены. Telegram на реальном телефоне не проверялся.

Ручная приёмка после публикации: удержать палец на Чудике — рамка не должна сжиматься; отпустить — он жмурится и улыбается. Проверить 4 реакции на каждом возрасте, быстрые повторы, смену формы/вида, возврат в спокойное состояние, слабую сеть и повтор после ошибки. В галерее действия не должны менять ресурсы. Проверить портреты на ширине 320–390 px, прокрутку и safe-area, Escape/Tab, reduced-motion.
