# Реакции всех питомцев

8 ноября 2026, МСК.

Добавлены 36 прозрачных листов по 16 кадров: 12 видов × 3 возраста = 576 кадров. В каждом листе четыре последовательности: поглаживание, еда, игра, отдых. Радость от награды использует улыбку и игровые позы. У Чудика сохранена прежняя, более подробная последовательность поглаживания и моргания.

Персонаж меняет нарисованную позу отдельно от неподвижного острова. Для небесных питомцев добавлен фон облачных островов. Действие начинается после загрузки выбранного возраста; повторное касание отменяет предыдущий таймер. При повышении уровня после действия предварительно загружается новая форма. При ошибке загрузки остаётся прежняя иллюстрированная реакция; повторная попытка может восстановить анимацию. В скрытой вкладке и вне экрана таймер кадров остановлен; при возвращении используется прошедшее время. При reduced-motion показывается выразительный неподвижный кадр.

Изображения запрашиваются напрямую в 2×, включая предзагрузку. Прозрачный кадр — 704×704, лист — 2816×2816. При экспорте каждый кадр сохраняет пропорции и получает 5% прозрачного поля с каждой стороны. Исходные PNG генератора сохранены в рабочем пространстве; в исходниках проекта — их lossless WebP-копии. Экспорт 2× увеличивает исходный растр и не создаёт дополнительных нарисованных деталей.

В сборку входят только используемые 2×-варианты; исходники и 1× сохранены в Git. После готовности анимации скрытые полноразмерные иллюстрации снимаются с DOM, чтобы не держать лишний слой. Все 36 листов одновременно не предзагружаются.

Проверки: npm test (17 тестов), npm run typecheck; размеры, непустые кадры и прозрачные границы проверяет node scripts/check-action-art.mjs. npm run build завершилась успешно; сборка содержит 60 прямых 2×-ресурсов, проверка подтвердила 36 листов и 576 непустых кадров с прозрачными границами. Браузерная и реальная телефонная проверка не подтверждены: инфраструктура preview ранее завершилась с EPERM. Художественные промежуточные кадры требуют просмотра на устройстве, особенно широкие крылья и хвосты, мягкие края и переходы между возрастами.
