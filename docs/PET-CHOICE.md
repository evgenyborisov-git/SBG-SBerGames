# Выбор и смена питомца

9 ноября 2026, МСК.

Новый профиль создаётся с `petId: null`. После авторизации интерфейс показывает знакомство с 12 питомцами. Игрок выбирает карточку, может погладить друга в предварительном просмотре и подтверждает выбор. До успешного ответа сервера выбор не считается сохранённым.

У существующих профилей без поля `petId` сохраняется Чудик. Кнопка «Сменить питомца» находится на острове под иллюстрацией; выбор доступен и из карточки атласа. Смена бесплатна. Монеты, энергия, опыт, уровень, коллекционные знаки и флаги подарков общие для профиля и не сбрасываются. Новый друг сразу отображается в форме, соответствующей текущему уровню. Это не отдельная экономика для каждого вида и не платное открытие из раннего дизайн-предложения.

HTTP POST `/api/game`: `{action: "select_pet", petId: "luna"}` с прежними проверками авторизации, Origin, JSON и Idempotency-Key. Сервер допускает только 12 известных ID. В журнале операция записывается как `select:<id>`, поэтому тот же ключ нельзя использовать для другого питомца. Повтор старого запроса возвращает актуальное состояние и не отменяет более поздний выбор. Общая транзакция D1 и контроль revision сохраняют одновременные игровые действия.

Схема SQL не меняется: выбор хранится внутри существующего JSON состояния. Старые записи читаются без сброса или массовой миграции. При сетевой ошибке клиент сохраняет тело запроса вместе с ключом и предлагает повторить сохранение; ошибка видна рядом с кнопкой выбора и в общем статусе.

Мобильные карточки используют отдельные Retina 2×-портреты 768×768 вместо четырёх больших атласов. Большие сцены и анимации также загружаются напрямую в 2×. Портреты — механические вырезки исходной графики; дополнительная детализация не заявляется.

Автоматические проверки: 21 тест, включая выбор всех видов, сохранение прогресса, наследование старого профиля, конкурентную смену с игрой, повтор/конфликт ключей, серверное чтение выбора, общие ежедневные награды и изоляцию пользователей. npm run typecheck и npm run build завершились успешно; сборка содержит 72 прямых 2×-изображения. Реальное открытие Telegram на телефоне и визуальная оценка мобильной страницы остаются отдельной приёмкой.

Ручная проверка: новый профиль → выбрать друга → поиграть → закрыть и открыть мини-приложение → убедиться в сохранении выбора и ресурсов → «Сменить питомца» → проверить тот же уровень и награды. Проверить повтор сохранения на медленной сети, все четыре реакции, все три формы, узкий экран и reduced-motion. Браузер и Telegram имеют разные профили.
