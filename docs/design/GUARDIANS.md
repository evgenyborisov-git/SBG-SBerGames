## Характеры и задания для иллюстраций

Для каждого героя сохранить силуэт и узнаваемые признаки во всех трёх формах. Реакции: спокойствие, еда, игра, ласка, сон, радость. Взрослый герой не должен превращаться в малыша при показе эмоции.

### Чудик · Мятный лисёнок
Любопытный и ласковый; первым встречает игрока.
**Облик:** Мятная шерсть, кремовая грудка, уши-листья, росток на голове; в финале прозрачные крылья.
**Реакции:** Хрустит морковкой / ловит солнечный мяч / щурится от ласки / сворачивается хвостом.

### Луми · Лунный зайчик
Тихий мечтатель; бережёт добрые сны.
**Облик:** Сиренево-белая шерсть, длинные уши, лунная отметина; в финале светящаяся лунная вуаль.
**Реакции:** Жуёт листик / прыгает за луной / складывает уши сердцем / спит в ушах-одеяле.

### Искорка · Персиковый дракон
Смелый непоседа; учится управлять своими искрами.
**Облик:** Персиковая чешуя, маленькие рожки и крылья; огонь похож на безопасные золотые искры.
**Реакции:** Печёт морковку дыханием / гоняет искру / прижимает крылья / дремлет у тёплого камня.

### Капля · Облачная выдра
Игривый исследователь; находит чудеса в каждой капле.
**Облик:** Голубоватая шерсть, округлая мордочка, плавный хвост; финальная водяная лента вокруг лап.
**Реакции:** Ловит угощение лапами / жонглирует пузырями / кувыркается / спит на облачке.

### Лучик · Солнечный совёнок
Добрый наблюдатель; замечает то, что остальные пропускают.
**Облик:** Золотистое оперение, крупные глаза, круглый силуэт; финальная корона из перьев-лучей.
**Реакции:** Клюёт зёрнышко / ловит солнечный блик / наклоняет голову / прячет клюв в крыло.

### Флора · Цветочный оленёнок
Заботливая садовница; оставляет цветы на своих тропинках.
**Облик:** Светлая шерсть, пятнышки-лепестки, веточки-рожки; финальные рога с цветами.
**Реакции:** Ест бутон / скачет по цветам / раскрывает цветок / ложится в лепестки.

### Мохик · Моховой ёжик
Немного застенчивый коллекционер; собирает лесные сокровища.
**Облик:** Округлый зелёно-коричневый силуэт; мягкие иголки-мох, пара грибочков; финальная мини-роща на спине.
**Реакции:** Держит ягодку / катится клубочком / выглядывает из мха / прячется в листьях.

### Шурша · Янтарная белочка
Быстрая выдумщица; мастер маленьких сюрпризов.
**Облик:** Рыже-медовая шерсть, очень большой хвост-завиток, янтарная подвеска; финальный хвост с искорками.
**Реакции:** Грызёт орешек / ловит шишку / обнимает хвост / спит в хвосте-гнезде.

### Тиша · Кристальный барсучок
Спокойный мастер; помогает друзьям находить дорогу.
**Облик:** Серо-кремовые полоски, короткие лапы, прозрачный кристальный гребень; финальные голубые грани на спине.
**Реакции:** Держит корешок / собирает башенку / довольно топает / зарывается в мягкий мох.

### Нимб · Небесный китёнок
Неспешный путешественник; возит облака между островами.
**Облик:** Сине-белый силуэт кита, маленькие плавники и звёздные веснушки; финальная полупрозрачная облачная мантия.
**Реакции:** Ловит воздушную ягодку / пускает кольца / переворачивается животом / качается в облаках.

### Сия · Полярная рысь
Независимая, но преданная; освещает путь друзьям.
**Облик:** Белая шерсть, высокие уши с кисточками, голубые лапы; финальный шлейф северного сияния.
**Реакции:** Ест снежную ягодку / ловит свет / мурчит и трётся щекой / прячет нос в лапы.

### Астра · Звёздный грифон
Собирает друзей вместе; хранит историю всего острова.
**Облик:** Львиные лапы, короткий клюв и мягкие перья; кремово-золотая палитра, в финале широкие крылья с созвездиями.
**Реакции:** Ловит золотое зёрнышко / рисует звезду крылом / склоняет голову / укрывается крыльями.

## Объём художественной работы

Полный целевой комплект: 12 героев × 3 формы × 6 реакций = 216 состояний. Это объём планирования, не обещание готовых иллюстраций. Для первого выпуска — 36 базовых форм, затем реакции по главам. Допустимо использовать анимацию базовой формы и реплику до готовности отдельной иллюстрации; облик стадии сохраняется.

Уже есть: три формы Чудика, шесть иллюстрированных состояний малыша и шесть концептов галереи. Концепты не считать готовыми тремя формами каждого героя. Новые иллюстрации создаются отдельно, существующие оригиналы сохраняются.

Общие требования: мягкий объёмный стиль, читаемый силуэт на 96 px, различимые эмоции, безопасные поля, без текста в изображениях. Фон острова и персонаж по возможности отдельными слоями. Брендовые акценты — в UI и окружении, без случайных логотипов на питомцах. Поддержать уменьшение движения.
