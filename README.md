# SBerGames · Чудо Lab

Telegram Mini App — тестовая версия игры с питомцем.

## Согласованный MVP

- Один питомец и его изображение.
- Кормление, энергия, эволюция.
- Коллекция.
- Ежедневная награда.
- Тестовый оффер.
- Серверное сохранение прогресса.
- Защита от повторного начисления наград.
- Партнёрские подтверждения и розыгрыши — только тестовый режим.

## Статус

Восстановление проекта после потери временной среды разработки. Этот репозиторий является постоянным источником исходников. Интерфейс, сервер, база данных и тесты должны быть восстановлены и проверены заново; прежний работающий стенд пока не подтверждён.

## Безопасность

Не сохранять токены Telegram, ключи API, пароли и другие секреты в репозитории и резервных копиях.
