# SBerGames · Чудо Lab — MVP 0.1

Тестовая игра с одним питомцем. Исходный локальный прототип сохранён в `docs/prototype.html`; рабочее приложение — `app/`, сервер — `lib/game/`.

## Реализовано

- Кормление: −5 монет, до +20 энергии, +10 XP.
- Игра: −15 энергии, +25 XP, +3 монеты. Пауза между игровыми действиями — 1,5 секунды.
- +1 энергии в минуту по серверным часам, максимум 100.
- Каждые 100 XP: уровень и +25 монет. Эволюция на уровнях 2 и 3, три коллекционных знака.
- Ежедневно +20 монет, граница дня — Europe/Moscow.
- Тестовый оффер +15 монет один раз на профиль.
- D1 хранит прогресс и журнал запросов. Атомарная транзакция с проверкой версии защищает от гонок; ключ запроса — от повторов.
- Серверная проверка Telegram initData: HMAC с TELEGRAM_BOT_TOKEN или Ed25519 с TELEGRAM_BOT_ID. Срок входа — 1 час.
- Браузерный тест через авторизацию ChatGPT. Профили браузера и Telegram разделены.

## Запуск

Node 22.13+; `npm ci`, `npm test`, `npm run typecheck`, `npm run build`.
Миграции: `npm run db:generate`. Перед локальным запуском применить SQL из `drizzle/` к локальной D1 через Wrangler с конфигурацией из сборки. `npm run dev` — разработка. Production — Cloudflare Worker с D1 через Sites.

## Telegram

Стартовый стенд закрыт владельцу. Для запуска в Telegram:
1. Настроить TELEGRAM_BOT_ID (числовой ID) либо секрет TELEGRAM_BOT_TOKEN в окружении хостинга.
2. В BotFather указать HTTPS-адрес в Main Mini App / Menu Button, обеспечить доступность стенда для тестировщиков.
3. Проверить запуск и восстановление профиля на телефоне.

Бот пока не подключён: ID/токен не предоставлены. Код интеграции готов, реальный Telegram-вход не проверен. Не сохранять секреты в исходниках и архивах.

## Проверки

Автотесты: экономика, эволюция, московская полночь, одноразовые награды, энергия, подделанные и устаревшие подписи. Тест с локальным D1/Miniflare отправляет 20 параллельных запросов ежедневной награды и 10 одинаковых запросов оффера: начисление должно быть единственным. Проверяется разделение профилей.

## Ограничения

Только тестовые монеты. Платежей, реальных партнёров и розыгрышей нет. Журнал запросов пока не очищается. Старый localStorage не импортируется. При сбое повторяется прежний ключ операции.

Архив исходников: Google Drive `ChatGPT/SberGames_Chudo_Lab`. Архив исходников не является копией пользовательской базы D1.
